# CoLab Software

> CoLab is an AI-powered design review platform for engineering and product-development teams. It combines collaborative CAD viewing, AI peer checking, and automated lessons-learned capture so teams can run faster virtual design reviews and turn engineering knowledge into decisions. CoLab publishes a REST-based Enterprise API (50+ endpoints) for two-way integration — provisioning workspaces and users, importing files and feedback, and extracting review activity — access is currently gated behind an Enterprise waitlist.

## Product
- [CoLab Software](https://www.colabsoftware.com/): AI-powered design review platform for engineering teams.
- [Enterprise API](https://www.colabsoftware.com/integrations/api): REST API with 50+ endpoints covering workspaces, users, roles, directories, files, reviews, feedback, and comments; audit logging on all actions; TLS in transit, AES-256 at rest, edge rate limiting. Enterprise access via waitlist.
